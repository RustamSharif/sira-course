Интерактивный курс по Сире Пророка Мухаммада ﷺ
Образовательный веб-тренажёр и справочное пособие по жизнеописанию (Сире) Посланника Аллаха ﷺ. Проект разработан для запуска в качестве Telegram Mini App (через GitHub Pages) или локального использования в браузере.
Особенности курса
190 проверочных вопросов с подробными историческими пояснениями к каждому ответу.
Режим работы над ошибками после прохождения каждого теста и возможность перемешивания вопросов.
7 структурированных шпаргалок для быстрого повторения имён, дат, родословной и ключевых событий.
Адаптивный интерфейс с комфортной газетной цветовой палитрой, крупным шрифтом и исламским геометрическим орнаментом.
Система контроля доступа по Telegram ID (`auth.js`).

Структура файлов проекта
Системные файлы
`index.html` — главное меню (оглавление) курса с навигацией по всем разделам.
`auth.js` — модуль авторизации Telegram WebApp, проверки списка допущенных пользователей (`ALLOWED_USERS`) и отображения информации об авторских правах.
Основной курс (хронология)
`sira_part1_pre_islamic_v4.html` — Часть 1. Доисламский период: родословная Пророка ﷺ до 6-го колена, дяди и тёти, кормилицы, молочные родственники, история колодца Зам-зам и Год Слона (25 вопросов + шпаргалка).
`sira_part2_birth_to_prophethood_v3.html` — Часть 2. От рождения до начала пророчества: первые 40 лет жизни, детство в Бану Са'д, сиротство, поездка в Шам и встреча с Бахирой, брак с Хадиджей, перестройка Каабы и уединение в пещере Хира (25 вопросов + шпаргалка).
`sira_part3_meccan_period.html` — Часть 3. Мекканский период: 13 лет пророчества, первые откровения, тайный и открытый призыв, переселение в Эфиопию, бойкот, Год скорби, аль-Исра валь-Мирадж, присяги при Акабе и Хиджра (25 вопросов + шпаргалка).
`sira_part4_medinan_period.html` — Часть 4. Мединский период и кончина Пророка ﷺ: устройство общины в Медине, битвы при Бадре, Ухуде и у Рва, Худайбийское перемирие, Открытие Мекки, Прощальный хадж и кончина Посланника Аллаха ﷺ (25 вопросов + шпаргалка).
Тематические модули и итоговая аттестация
`sira_extra1_family_and_wives.html` — Доп. модуль 1. Семья Пророка ﷺ (Ахль аль-Байт): Матери правоверных (11 жён), 7 детей, внуки и близкие домочадцы (25 вопросов + шпаргалка).
`sira_extra2_companions.html` — Доп. модуль 2. Выдающиеся сподвижники: десять обрадованных Раем, почётные титулы сахабов, хранители Корана, великие ансары и сподвижницы (25 вопросов + шпаргалка).
`sira_final_exam_40.html` — Итоговый экзамен: комплексная проверка знаний по всем темам курса (40 вопросов + сводная хронология).

Настройка доступа (для администратора курса)
Откройте файл `auth.js` для редактирования.
Впишите свой цифровой Telegram ID (можно узнать через бота `@userinfobot`) и ID учеников в массив `ALLOWED_USERS`.
Укажите свой контакт для связи в переменной `CONTACT_LINK` и данные правообладателя в `COPYRIGHT_TEXT`.
Опубликуйте репозиторий через Settings → Pages и подключите полученную HTTPS-ссылку к боту через `@BotFather` (`/setmenubutton`).
