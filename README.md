Интерактивный курс по Сире Пророка Мухаммада ﷺ
Образовательный веб-тренажёр и справочное пособие по жизнеописанию (Сире) Посланника Аллаха ﷺ. Проект разработан для запуска в качестве Telegram Mini App (через GitHub Pages) или локального использования в браузере.
Особенности курса
190 проверочных вопросов с подробными историческими пояснениями к каждому ответу.
Режим работы над ошибками после прохождения каждого теста и возможность перемешивания вопросов.
7 структурированных шпаргалок для быстрого повторения имён, дат, родословной и ключевых событий.
Адаптивный интерфейс с комфортной газетной цветовой палитрой, крупным шрифтом и исламским геометрическим орнаментом.
Система контроля доступа по Telegram ID (`auth.js`).
